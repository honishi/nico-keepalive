# 機能仕様メモ

## 監視の基本挙動
- `video.currentTime` を 5 秒間隔で監視し、約 20 秒間変化しない場合を停止扱いにする。微小揺れはノイズとして無視する。
- 監視開始から 60 秒はウォームアップとして判定をスキップする。
- `paused` / `ended` / 追いかけ再生中は監視基準をリセットしてスキップする。
- 番組メタ（放送者名 / ON_AIR）は `#embedded-data` の `data-props` から取得し、Offline の場合は監視しない。

## 高度な停止チェック
- 映像フレーム比較 + 音声解析により、「映像変化なし かつ 無音」が一定時間続く場合も停止扱いにできる。
- 現状の既定値は ON。
- 判定時間は popup から変更可能。範囲は 20 秒から 5 分、既定値は 1 分。
- `AudioContext` / `captureStream` / 音声トラック取得不可などで deep check が使えない場合は、そのページでは通常判定にフォールバックする。

## 停止検知後の挙動
- 停止判定後は 5 秒カウントダウンを表示し、`window.location.reload()` を実行する。
- 停止検知中は二重にカウントダウンしない。
- 自動リロード回数を記録し、`lastReloadAt` とあわせて保存する。
- 放送停止検出時に通知音を再生できる。デフォルト音 / カスタム音 / 音量設定に対応する。

## フルスクリーン復元
- リロード前にフルスクリーン状態を保存する。
- リロード後にフルスクリーン復元を最大 5 回リトライする。
- フルスクリーン復元用の状態は 24 時間で破棄する。

## Overlay とデバッグ
- monitor overlay を popup から表示できる。現状の既定値は ON。
- overlay には通常判定 / 高度な停止判定 / warmup / paused / ended / 追いかけ再生の状態を表示する。
- overlay は初期状態で最小化され、ドラッグ移動できる。
- overlay 上で、そのページだけ監視と自動リロードを一時的に ON/OFF できる。状態は永続化しない。
- `__DEV__` では popup から warmup / 通常判定 / deep 判定を個別に ON/OFF できる。

## 開発用ショートカット（`__DEV__` のみ）
- `Ctrl+T`: トースト表示のテスト
- `Ctrl+D`: フルスクリーン状態のログ出力
- `Ctrl+F`: フルスクリーン切替
- `Ctrl+R`: 停止検知のシミュレート（入力中は無効）
